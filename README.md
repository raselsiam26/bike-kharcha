# বাইক খরচা 🏍️
বাইকের তেল ও অন্যান্য খরচের হিসাব রাখার ফ্রি ওয়েব অ্যাপ (HTML/CSS/JS, কোনো বিল্ড লাগে না)।

## লাইভ করার ধাপ
1. GitHub-এ নতুন repository বানাও, এই ফোল্ডারের সব ফাইল আপলোড করো।
2. vercel.com-এ GitHub দিয়ে লগইন, Add New → Project, repo সিলেক্ট করে Deploy।
3. লিংক পেলে `index.html`-এ `og:image` এর মান `https://তোমার-লিংক/og.png` করে দাও।

## নিজের ফেসবুক লিংক বসানো
`index.html`-এ ফেসবুক লিংক ইতিমধ্যে বসানো আছে; বদলাতে `id="fb"` খুঁজো।
